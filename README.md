# Student Management \& Performance Analysis System



## Project Description



The Student Management \& Performance Analysis System is a Python-based application developed to manage student information and analyze academic performance.



The system provides a simple graphical user interface for adding, viewing, searching, updating and deleting student records.



It also performs data analysis, visualization and basic machine learning prediction.



## Features



\- Add student records

\- View student records

\- Search students by name or roll number

\- Update student information

\- Delete student records

\- Calculate average marks

\- Perform statistical data analysis

\- Generate graphs and visualizations

\- Predict Pass/Fail using Decision Tree

\- MySQL database integration

\- Graphical User Interface using Tkinter

\- Median

\- Average marks

Matplotlib and Seaborn are used to create:

The model uses:



\- Mathematics marks

\- Python marks

\- Computer Networks marks

\- WAD marks

\- Attendance
